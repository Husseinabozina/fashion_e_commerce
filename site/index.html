05 / PROJECT SCOPE

Explore it.
Know its scope.

NOVA is a portfolio application with sample catalog data and virtual transactions. It demonstrates product design and implementation without operating a real store.

Run the project ↗Android releases ↗

The October 3 Android release is an earlier sandbox snapshot and predates the current identity shown here. Build from source for the current version.

What works in this demo +

Browsing, search, saved products, bag changes, promotions, addresses, accounts and demo order receipts. Firebase-backed state and a separate in-memory showcase mode are available. Arabic and English are supported.

How test payments work +

The public MyFatoorah sandbox uses a fixed virtual 1 KWD charge, separate from the sample EGP basket total. No real money moves. NOVA must be open to verify the result; there is no background payment webhook. Availability depends on the provider.

What is outside the demo +

Live charges, stock fulfillment, real shipping and operational refunds are outside this project. Push registration and notification functions are implemented, but automated push delivery is not deployed.

About the visuals +

Screens and footage are from the running app, captured on October 5, 2026. Product images, names and prices are illustrative sample content; brand labels do not imply partnership or verified inventory.
